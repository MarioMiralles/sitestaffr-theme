Greeting Tone Preview Samples
=============================

Place pre-recorded MP3 files in this folder for Settings -> Custom Greeting tone previews.

Expected filenames:
- `warm_neutral.mp3`
- `upbeat_friendly.mp3`
- `calm_professional.mp3`
- `serious_respectful.mp3`

Each file should use a generic line (no business-name interpolation), for example:
"Hi! Thanks for reaching out. How can we help you today?"

The Settings page preview button loads:
`assets/audio/greeting-tone-samples/{tone}.mp3`
